Data Cleaning Logic

Tư duy truy vấn SQL thực chiến

Minh họa kỹ thuật khử trùng lặp và lấp dữ liệu khuyết thiếu bằng Window Functions thay vì xóa thủ công:

WITH RowNumCTE AS (
  SELECT *,
    ROW_NUMBER() OVER (
      PARTITION BY ParcelID, PropertyAddress, 
                   SalePrice, LegalReference
      ORDER BY UniqueID
    ) AS row_num
  FROM NashvilleHousing
)
DELETE FROM RowNumCTE 
WHERE row_num > 1;
